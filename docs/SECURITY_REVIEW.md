## Beyond §9

- **CSRF:** every mutating request must carry an `Origin` equal to the server's own origin (`server/src/plugins/security.ts`); mismatches are logged as `csrf.origin_mismatch`. Tested in `server/test/auth.test.ts` and `server/test/setup.test.ts`.
- **Error handling:** one handler (`server/src/errors.ts`) maps Zod → 400, `HttpError` → its status, Fastify 4xx → their status, and anything else → `500 { error: "internal" }` with the stack kept in the log only. Unknown `/api` paths answer JSON 404 on every method rather than the SPA shell. Proven in `server/test/hardening.test.ts` "error handling" and `server/test/app.test.ts`.
- **Secrets in logs and events:** `settings.updated` carries key names only; the HA token never appears in responses, events, or logs (`server/test/settings.test.ts`, `server/test/settings-routes.test.ts`).
- **Backups:** `GET /api/backup` is admin-only, uses `VACUUM INTO` a temp file under `DATA_DIR` (the path is our own, quoted), and deletes it after streaming; `Cache-Control: no-store` (`server/test/backup.test.ts`). The copy includes the encrypted HA token, which is only useful together with `secret.key`.
